This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses Next.js with OpenNext for Cloudflare Workers.

## Deploy on Cloudflare Workers

Configure the required Supabase and payment environment variables in Cloudflare, keeping private credentials in Worker secrets. See [BOOKINGSETUP.md](./BOOKINGSETUP.md) for the production environment and callback checklist.

Deploy the OpenNext Worker with:

```bash
npm run deploy
```
